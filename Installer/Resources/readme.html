安装说明

应用将安装到 /Applications/Codex Quota.app。安装结束后，从“应用程序”打开 Codex Quota。

请先安装并登录 Codex。额度读取依赖本机 Codex 的 app-server 接口；目前已在 0.155.0-alpha.9 验证，其他版本是否兼容取决于接口支持。

仅返回周额度时显示周余量，悬停与详情说明额度类型。没有返回 5 小时窗口并不代表无限制。

若旧版正在运行，请先从其下拉菜单退出，再打开新安装的版本。本安装不会设置开机启动，不会修改 Codex 登录配置。

这是本地构建的安装包，未经过 Apple Developer ID 签名或公证。
