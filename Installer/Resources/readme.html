安装说明 / Installation notes

安装到 /Applications/Codex Quota.app，并为此 Mac 的用户安装登录启动监听。当前登录用户的旧监听配置将迁移，旧额度进程将重启。需要已安装并登录的 Codex、Apple Silicon 和 macOS 14+。本安装包没有 Developer ID 签名或 Apple 公证。

Installs to /Applications/Codex Quota.app and adds a login listener for users on this Mac. Migrates the console user’s earlier listener and restarts their quota process. Requires logged-in Codex, Apple Silicon, and macOS 14+. No Developer ID package signature or Apple notarization.
