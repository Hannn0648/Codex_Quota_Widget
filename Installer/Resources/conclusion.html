安装完成 / Installation complete

当前系统的登录用户将自动启动后台监听；如未启动，请从“应用程序”打开 Codex Quota。Codex 运行时显示额度，完全退出时隐藏并停止查询。后台监听保留；关闭窗口不等于退出。其他登录用户请重新登录或重新打开应用。其他系统卷安装在下次登录时生效。

The console user’s listener starts automatically on the current system. If needed, open Codex Quota from Applications. Quota appears while Codex runs; fully quitting hides it and stops queries. The listener remains active; closing a window is not quitting. Other active users should log in again or reopen the app. Other target volumes activate at the next login.
